## 💡 Recomendaciones del Gestor de Configuración (ITIL)

1. **Gestión de Cambios:** Todo requerimiento nuevo o corrección de error debe nacer indispensablemente de un Issue en GitHub antes de iniciar el código.
2. **Convención de Commits:** Respetar la redacción en tiempo presente (`feat(modulo): descripcion`) según lo establecido en [`CONTRIBUTING.md`](../CONTRIBUTING.md).
3. **Seguridad en Supabase:** Verificar que cada tabla creada cuente con sus políticas RLS (Row Level Security) antes de abrir un Pull Request.
4. **Pruebas Locales:** Ejecutar pruebas de no regresión antes de solicitar la revisión al Configuration Manager (**Juan Carvajal**).
