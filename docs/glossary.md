# 📖 Glosario de Términos del Sistema

Este documento define la terminología clave utilizada en el **Sistema de Gestión y Venta de Pasajes Interprovinciales** para asegurar un entendimiento común entre el equipo de desarrollo.

---

## 🚌 Términos del Dominio de Transporte

* **Cooperativa:** Empresa u organización de transporte interprovincial legalmente constituida que administra una flota de buses.
* **Frecuencia:** Horario e itinerario asignado a un bus para cubrir un trayecto específico entre un origen y un destino.
* **Sub-ruta / Parada Intermedia:** Punto intermedio en el trayecto de una frecuencia donde los pasajeros pueden abordar o desembarcar.
* **Boleto Digital:** Comprobante de viaje en formato electrónico (con código QR o integrado a billeteras virtuales) que acredita el derecho a transporte.
* **Trazabilidad de Pasajeros:** Registro histórico del listado de abordaje de pasajeros por unidad de bus para control operativo y de seguridad.
* **Validación de Descuento:** Proceso de verificación de documentos probatorios para la aplicación de tarifas preferenciales (niños, personas con discapacidad o tercera edad).
